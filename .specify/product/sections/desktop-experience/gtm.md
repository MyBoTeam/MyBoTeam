## 11.5 Go-to-Market Strategy

**Purpose**: Define how the desktop product shell should be positioned to users.

### 11.5.1 Launch Phases

#### Phase 1: Guided Desktop Introduction

| Attribute | Details |
|-----------|---------|
| **Audience** | New mainstream desktop users |
| **Goal** | Make the app feel approachable and useful immediately |
| **Entry Criteria** | Guided onboarding and clear first-task path |
| **Success Metrics** | Onboarding completion and first-task completion |
| **Exit Criteria** | Users return after first use |

#### Phase 2: Configurable Retention

| Attribute | Details |
|-----------|---------|
| **Audience** | Returning users |
| **Goal** | Show that the shell supports deeper control without clutter |
| **Entry Criteria** | Settings coherence and trustful defaults |
| **Success Metrics** | Better repeat usage and lower settings confusion |
| **Exit Criteria** | Advanced users engage without hurting mainstream UX |

#### Phase 3: Broader Desktop Maturity

| Attribute | Details |
|-----------|---------|
| **Audience** | Users comparing desktop assistant products |
| **Goal** | Position the shell as both polished and capable |
| **Entry Criteria** | Stable onboarding, settings, and locale truthfulness |
| **Success Metrics** | Stronger product preference and retention |
| **Exit Criteria** | Desktop shell supports broader growth |

#### Phase 4: Premium Surface Expansion

| Attribute | Details |
|-----------|---------|
| **Audience** | Repeat users likely to adopt future paid value |
| **Goal** | Layer future premium surfaces without breaking the free core |
| **Success Metrics** | Future premium adoption and continued free-core retention |

### 11.5.2 Pricing Strategy

| Tier | Price | Includes | Target Segment |
|------|-------|----------|----------------|
| **Free** | $0 | Full desktop core experience, guided onboarding, and current shipped settings surface | Broad simple users |
| **Curated Bundles** | Future pricing | Additional packaged workflow value layered on the shell | Returning users |
| **Enterprise** | Not current scope | No present commitment | Not current target |

### 11.5.3 Key Messaging

**For mainstream users:** "A personal AI desktop app that helps you get useful work done without making setup the whole experience."

**For returning users:** "Start simple, then reveal more control only when you need it."

**For future power users:** "The desktop shell is built to grow with you without abandoning the free core."

### 11.5.4 Success Metrics by Phase

| Phase | Adoption Target | Engagement Target | Revenue Target |
|-------|----------------|-------------------|----------------|
| Guided Desktop Introduction | Strong onboarding and first-task completion | Early return usage | None |
| Configurable Retention | More returning users | Lower settings confusion | None |
| Broader Desktop Maturity | Strong shell preference | Better retention | Pre-revenue validation |
| Premium Surface Expansion | Future paid adoption | Continued reuse | Future commercial target |

### 11.5.5 Channel Strategy

| Channel | Purpose | Target | Investment |
|---------|---------|--------|------------|
| In-product onboarding and UI | Deliver the product promise directly | New users | High |
| Product site, README, and community messaging | Set expectations accurately about current scope | Broader desktop audience | Medium |
